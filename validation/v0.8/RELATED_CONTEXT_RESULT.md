# v0.8 related-context result

Date: 2026-08-11

Status: PASS for the local disclosure-safety contract. External answer-quality evidence remains
unvalidated.

## Decision

One-hop graph neighbors are proposals, not approved context. Each proposal displays its direction
and relation, receives a stable `rN` review number, and enters the brief only when the user types
that exact number in the existing add step. Blank input approves none.

Supported relation labels are `calls`, `called-by`, `imports`, `imported-by`, `references`,
`referenced-by`, `contains`, and `contained-by`. At most ten related proposals are displayed.

## Verified properties

- selecting a primary candidate does not include any related path, symbol, import, note, boundary,
  or source excerpt by default;
- entering `rN` promotes only that related node to explicit selected context;
- duplicate edges combine into one proposal with multiple deterministic relation labels;
- excluded nodes cannot re-enter through the related proposal set;
- second-hop nodes are not proposed from an unapproved first-hop node;
- source disclosure continues to consider only explicitly selected non-module nodes;
- the existing per-excerpt preview, boundary `EXPOSE`, and final exact `WRITE` approvals remain in
  force;
- the maximum related proposal count on the frozen benchmark is 10.

## Limits

The tests prove selection and disclosure behavior, not that approving related context improves an
external model's answer. A real user field trial is still needed before making that product claim.
The product also does not classify secrets and does not approve an export as safe.
